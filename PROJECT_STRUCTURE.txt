Methodology_4 — project structure
Generated 2026-07-21. Paste this into Claude Desktop for context.

.
├── Options.py                  Asset classes (CostaHead, HestaHead, NewLink,
│                                Stage1_Wind_Buildout, Stage2_Wind_Buildout,
│                                Extra_Link) — capacity, capex, opex, classification
│                                per generation/link option.
├── Model_Components.py         Decision, Generation_Capacity, Link_Capacity,
│                                Existing_link, Existing_Generation — tracks
│                                built assets over time and aggregates capacity/opex.
├── Demand.py                   Builds demand scenarios (base + DFES deltas) in GWh:
│                                base, Demand_EE, Demand_FB, Demand_HT, Demand_HE.
│                                Reads Extra/Data/dfes_demand_delta_GWh.csv.
├── System_Model.py              Main entry point. Runs each strategy (Strategies_2)
│                                against each demand scenario, computes hourly
│                                generation/demand/link balance and LCOE.
│                                Imports Extra.Extra_Code.Wind_CF for the hourly
│                                wind capacity-factor profile (WIND_CF) and loads
│                                Extra/Data/dem_shape_2019.npy for the hourly
│                                demand shape.
│
├── Extra/
│   ├── Extra_Code/              Supporting/prep scripts (not imported by the
│   │   │                        main model except Wind_CF.py).
│   │   ├── Wind_CF.py           Loads Renewables.ninja hourly wind CF from
│   │   │                        Extra/Data/Ninja_Wind_CF.csv -> WIND_CF (imported
│   │   │                        by System_Model.py). Exports wind_cf_2019.npy.
│   │   ├── PV_CF.py             Same pattern for solar PV, from
│   │   │                        Extra/Data/Ninja_PV_CF.csv -> PV_CF (not yet wired
│   │   │                        into System_Model — PROFILES["PV"] is a zeros
│   │   │                        placeholder there).
│   │   ├── DFES_Demand.py       Builds dfes_demand_delta_GWh.csv from
│   │   │                        Extra/Data/2025_DFES_Projections.csv (EV + heating
│   │   │                        demand increments by DFES scenario). Writes back
│   │   │                        into Extra/Data/.
│   │   ├── DFES_Gen.py          Builds dfes_generation_MW.csv (background DFES
│   │   │                        generation buildout, excl. Decision-modelled
│   │   │                        assets) from the same projections CSV. Writes
│   │   │                        into Extra/Data/.
│   │   ├── EV_Fcator.py         Derives kWh-per-EV-car factor from
│   │   │                        Extra/Data/Traffic_Volume.csv + DfT licensing data.
│   │   ├── Hourly_For_CF.py     Builds the normalised 8760-hour demand shape
│   │   │                        (dem_shape_2019.npy) from raw minute ANM data in
│   │   │                        the SEPARATE "Forecasting - Week 1" project.
│   │   │                        Output now written to Extra/Data/.
│   │   └── Generation.py        Cleans raw generation data, also from the
│   │                            separate "Forecasting - Week 1" project
│   │                            (paths there were NOT changed — different project,
│   │                            untouched by this reorg).
│   │
│   └── Data/                    All CSV/npy/reference data the Extra_Code
│       │                        scripts read from and write to.
│       ├── 2025_DFES_Projections.csv
│       ├── Ninja_Wind_CF.csv / .numbers
│       ├── Ninja_PV_CF.csv / .numbers
│       ├── Traffic_Volume.csv
│       ├── Licensed_Vehicles.ods
│       ├── REPD_publication_Q1_2026.xlsx
│       ├── Scotland_2019_DFES.pdf
│       ├── dfes_demand_delta_GWh.csv    (output of DFES_Demand.py, read by Demand.py)
│       ├── dfes_generation_MW.csv       (output of DFES_Gen.py)
│       ├── dem_shape_2019.npy           (output of Hourly_For_CF.py, read by System_Model.py)
│       └── pv_cf_2019.npy               (output of PV_CF.py)

   moved into Extra/Data/ (previously a flatter Extra/ layout).
2. Updated every hardcoded absolute path in Demand.py, System_Model.py, and all
   Extra_Code/*.py scripts to point at the new locations. Confirmed by running
   each script end to end.

   Renewables.ninja export has a metadata comment line containing the word
   "time" before the real header row, which was matching first and causing
   misparsed data. Now matches on the first CSV field being exactly "time".

   at the top (lines 1-3 repeat lines 6-8) — harmless, not cleaned up.
   Wind_CF.py's mean CF (0.617) is notably higher than the measured 2019 figure
