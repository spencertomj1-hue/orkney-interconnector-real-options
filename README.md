# orkney-interconnector-real-options

Real-options Monte Carlo model comparing rigid, staged, and flexible build strategies for the Orkney–Caithness electricity interconnector and generation expansion under demand, price, and wind uncertainty.

## Setup

Requires Python 3.11+ (developed on 3.13).

```
pip install -r requirements.txt
```

## Running

Entry points, in order:

1. **`Reporting/Results.py`** — the headline run. Runs the Monte Carlo (`RUN_MC=True`), prints the ENPV/CVaR/value-of-flexibility tables, writes plots to `Reporting/Results_Plots/`, and caches the draws to `Extra/MC_Cache/headline_mc.pkl` for the two scripts below.
2. **`Reporting/Sensitivities.py`** — parameter sweeps (discount rate, AVAIL, capex overrun, cost-aware trigger, etc.), loading the cache from step 1. Plots go to `Reporting/Sensitivities_Plots/`.
3. **`Reporting/ScenarioDiscovery/Scenario_Discovery.py`** — PRIM scenario discovery over the cached draws (requires `System_Model.SCENARIO_DISCOVERY = True`, the default, so step 1 has already written `Reporting/ScenarioDiscovery/Extra/mc_draws.csv`). Plots go to `Reporting/ScenarioDiscovery/Main_Plots/`.

Everything else in `Model/` is imported by these, not run directly (`Model/Decision_Rules.py` has its own self-test suite under `if __name__ == "__main__"`).

## Layout

- **`Model/`** — the simulation core: `System_Model.py` (the `Run_Strategy` engine), `Uncertainty.py` (weather/GBM/capex sampling), `Strategies.py` (rigid + flexible strategy factories), `Decision_Rules.py` (the flexible-strategy trigger logic), `Options.py`/`Model_Components.py` (asset and capacity-tracking classes), `Demand.py` (DFES demand scenarios).
- **`Reporting/`** — everything above, plus `_shared.py` (helpers shared across the three entry points).
- **`Inputs/Data_Processing/`** — one-off scripts that clean raw data into the CSVs/`.npy` files `Model/` reads (`Inputs/Data/`). Not part of the model's runtime path; re-run only if the raw source data changes.
- **`Extra/`** — `orkney_link_opex.py` (a standalone existing-link OpEx estimate), `MC_Cache/` (gitignored, regenerated by step 1), `PNZ2025_Presentation/` (reference tables).

## Data note

Most inputs live under `Inputs/Data/` and are included. A few `Inputs/Data_Processing/Generation/` scripts (`Generation.py`, `GBM_Calibration.py`'s demand/generation calibration) read from a sibling `Forecasting - Week 1/Data/` folder outside this repo — those are one-off calibration steps whose *outputs* (the GBM sigma estimates) are what `Model/` actually depends on, not the raw files themselves.
